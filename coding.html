Coding

Level 2 — Intermediate

Dari blok warna-warni sampai kode asli. Mulai dari Scratch, lanjut ke Arduino C++ dan Python.

Materi pembelajaran

  • Berpikir logika: urutan, perulangan, dan percabangan.
  • Scratch: blok perintah dan animasi sederhana.
  • Mengenal board Arduino dan Arduino IDE.
  • Struktur program Arduino: setup dan loop.
  • Variabel, kondisi (if/else), dan perulangan.
  • Membaca input sensor dan mengatur output.
  • Dasar Python untuk robotik.
  • Mencari dan memperbaiki kesalahan (debugging).

Praktik langsung

  • Membuat karakter bergerak di Scratch.
  • Membuat LED berkedip dengan kode Arduino.
  • Membuat robot berhenti saat sensor mendeteksi halangan.
  • Membuat program kecil sendiri dan mempresentasikannya.
Target

Bisa menulis program sederhana untuk menggerakkan robot sendiri.
